# homebrew-agentdfir

Homebrew tap for [AgentDFIR](https://github.com/efij/AgentDFIR), open-source
digital forensics and incident response for AI coding agents.

```sh
brew install efij/agentdfir/agentdfir
```

The formula is rendered and pushed by the AgentDFIR release workflow
(`scripts/update-tap.sh` in the main repository). Do not edit
`Formula/agentdfir.rb` by hand.
